# Swagger API Documentation Guide

# Problem-Service 
### Swagger UI

After starting the application, open one of the following URLs in your browser:

```text
http://localhost:8082/swagger-ui/index.html
```

or, if your project is configured to use the alternative path:

```text
http://localhost:8082/swagger-ui.html
```

---

###  OpenAPI JSON

Open the following URL:
```
http://localhost:8082/v3/api-docs
```

### Expected Result

The browser should display the OpenAPI specification in JSON format.

Example:

```json
{
  "openapi": "3.0.1",
  "info": {
    "title": "Problem Service API",
    "version": "v1"
  }
}
```

If this endpoint is accessible, it confirms that the OpenAPI documentation has been generated successfully.
